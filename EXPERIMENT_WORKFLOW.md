# Experiment Workflow

Use this project in a repeatable way with one command path.

## Quick Start
1. Ensure `.env` has valid model credentials.
2. Start from project root.
3. Run:

```bash
make exp-v1 MODEL=openai/gpt-4o-mini
```

This runs baseline + dual on `benchmarks/generated/case_pack_v1_50.json` and writes:
- `results/runs/<run-id>/baseline.jsonl`
- `results/runs/<run-id>/dual.jsonl`
- `results/runs/<run-id>/traces_baseline/*`
- `results/runs/<run-id>/traces_dual/*`
- `results/runs/<run-id>/summary.json`

## Useful Commands
- Re-sync from AgentDojo tasks:
```bash
make cases-sync
```

- Rebuild curated 50-case pack:
```bash
make cases-pack
```

- Run only one environment:
```bash
make exp-v1 MODEL=openai/gpt-4o-mini ENV=banking
```

- Run with limit:
```bash
make exp-v1 MODEL=openai/gpt-4o-mini LIMIT=10
```

- Summarize latest run again:
```bash
make summary-latest
```

## Notes
- `results/` is intentionally git-ignored.
- `external/` is git-ignored; keep your local AgentDojo clone there.
- Per-case deep traces are generated by `scripts/run_case_suite.py --trace-dir ...`.
